GOLDEN DAYLIGHT CINEMA - Source provenance record
===================================================

All source images are real photographs from Wikimedia Commons / Pexels /
Unsplash / CC0-licensed galleries.  No AI-generated imagery was used anywhere in
this project.  See README.txt for the project overview and Blackmagic Camera
instructions.  All previews (BEFORE/AFTER) derive from this same set; the inputs
to the .cube were *simulated* Apple Log 2 captures derived from these photos
(see SIMULATION NOTE below).  Simulation is fully labelled as such everywhere.

SIMULATION NOTE (important)
-------------------------
The .cube consumes Apple Log 2 encoded (0..1) input and outputs Rec.709 gamma
2.4.  Real iPhone 17 Pro footage was NOT available.  Every preview shows a
*simulated* Apple Log 2 capture derived from a real-world photograph:
  sRGB -> linear Rec.709 -> XYZ -> linear Apple Wide Gamut -> simulated
  sensor noise (photon-shot + read noise) -> Apple Log 2 OETF -> 8-bit PNG.
  The simulation is transparent and deterministic (seed 20261122, fixed
  per-channel noise model) and is clearly labelled as simulated in the gallery,
  previews, and PNG text metadata.  It does NOT represent genuine iPhone footage.

Notes
-----
- Previews are derived from these source photos: simulated Apple Log 2 was
  applied to each source, then the .cube was run through an independent
  parser for AFTER images.  BEFORE images use the neutral Apple Log 2
  reference transform.  Preview outputs AREN'T themselves new photographs.
- The simulated inputs are NOT iPhone 17 Pro footage and MUST NOT be presented
  as genuine sensor captures.
- If you wish to reproduce: run simulate_log.py then render_previews.py; the
  simulation is seeded and deterministic.

# GOLDEN DAYLIGHT CINEMA

A premium, standalone cinematic LUT for **Apple Log 2 / Apple Wide Gamut** footage from the
iPhone 17 Pro (recorded with Blackmagic Camera for iOS), delivering Rec.709 SDR at gamma 2.4.

* **LUT** — `GOLDEN_DAYLIGHT_CINEMA/LUT/GOLDEN_DAYLIGHT_CINEMA.cube` (33³)
* **Gallery** — `GOLDEN_DAYLIGHT_CINEMA/GALLERY/index.html` (8 interactive before/after scenes)
* **Validation** — `GOLDEN_DAYLIGHT_CINEMA/VALIDATION_REPORT.txt`
* **Install / usage** — `GOLDEN_DAYLIGHT_CINEMA/README.txt`
* **Reproducible build** — `build/` (curve + gamut from Apple's published white paper)

Status: in progress.
